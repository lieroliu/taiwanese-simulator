# 資料來源

## 統計資料（決定「發生什麼」）

| 用途 | 來源 | 細分程度 |
|---|---|---|
| 出生地抽選 | 內政部戶政司：各縣市出生數 | 縣市、年度 |
| 壽命 | 內政部統計處：簡易生命表 | 縣市、性別 |
| 死因 | 衛福部統計處：死因統計 | 年齡、性別、縣市 |
| 家庭收入 | 主計總處：家庭收支調查 | 所得五等分位、縣市 |
| 升學與教育 | 教育部統計處 | 各級升學率、學歷分布 |
| 工作與薪資 | 主計總處人力資源調查、勞動部職類別薪資調查 | 職業、年齡 |
| 結婚、離婚、生育 | 內政部戶政司 | 縣市、年齡 |
| 意外事件 | 交通部道安資料、警政署統計 | 年齡、縣市 |
| 過去與未來世代 | 國發會人口推估、各年度歷史統計 | 全國為主 |

多數可在 [政府資料開放平臺](https://data.gov.tw) 或各機關統計網頁下載 CSV。

### 交叉關係（出身如何影響人生）

政府統計多為單一面向，缺少「某出身背景 → 某結果」的交叉機率。可參考：

- 中研院「華人家庭動態資料庫（PSFD）」：追蹤同一批人多年
- 中研院「台灣社會變遷基本調查」

學術用途通常可申請使用。

### 已知限制

- 1950–60 年代統計多半未細分縣市，需以全台平均加推估
- 族群相關統計在早期較少，需以文獻補足

- 國家人權博物館受難者紀錄
