# 歷史事件時間軸（討論稿）

所有角色走在同一條時間軸上，差別在於事件發生時他幾歲、人在哪裡、是什麼出身、是什麼個性。
月份用來逐月觸發；標 ~ 的是持續一段時間的現象，觸發時間依區間隨機。

## 觸發規則

每個事件標一種觸發方式：

| 類型 | 說明 | 例子 |
|---|---|---|
| **全民** | 每個角色都會碰到，只是反應依性格和處境不同 | 921、疫情、解嚴 |
| **條件** | 只有符合族群、地區、年齡、職業或家庭條件的角色才會碰到 | 蘭嶼核廢料 → 原住民或台東 |
| **個性** | 符合條件的角色中，再依人格圖決定會不會在意 | 校園民歌 → 外向、冒險高的青少年才會迷；埋頭念書的人不會 |

「條件」欄空白代表全民事件。個性欄寫的是**提高**觸發機率的特質。
