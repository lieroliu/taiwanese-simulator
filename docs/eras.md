# 世代 × 身分矩陣（初稿）

「年代」定義為**出生世代**，角色從該世代出生，一路經歷之後的台灣。

> 設計觀察：早期世代的人生差異主要來自**族群與性別**，後期世代則越來越取決於**家庭所得與城鄉**，因此每個世代的身分軸不同。

---

## 1｜戰後世代（1945–1955 生）

**關鍵事件**：國語運動、戒嚴、加工出口區、十大建設、全民健保開辦（1995）

| 身分 | 處境 |
|---|---|
| 本省閩南 | 在家講台語，在學校講會被罰；父母對過去的事絕口不提 |
| 外省 | 眷村長大，父親的鄉愁與「回不去的家」 |
| 客家 | 語言雙重弱勢，進城後習慣隱藏身分 |
| 原住民 | 被改漢名，離開部落到都市做工或跑遠洋 |
| 女性（跨身分） | 國小畢業就進工廠，賺錢供兄弟讀書 |

**心境主題**：沉默、匱乏、犧牲自己換下一代

---

## 2｜70 年代生（1970–1979）

**關鍵事件**：聯考、解嚴（1987）、野百合學運（1990）、亞洲金融風暴（1997）、SARS（2003）

| 身分 | 處境 |
|---|---|
| 小生意或工廠家庭 | 補習人生，「考上大學就翻身」 |
| 外省第二代 | 本土化浪潮中的身分認同搖擺 |
| 客家、原住民 | 還我母語運動、原住民正名，第一次能公開說「我是誰」 |
| 女性（跨身分） | 大量進入大學與職場，開始在事業和婚育間拉扯 |

**心境主題**：努力就有回報的信念；中年成為三明治世代

---

## 3｜80 年代生（1980–1989）

**關鍵事件**：台灣錢淹腳目、921 地震（1999）、教改、22K（2009）、太陽花學運（2014）

| 身分 | 處境 |
|---|---|
| 雙北中產 | 才藝班長大，出社會才發現學歷貶值 |
| 中南部農工家庭 | 北上工作，回不去也留不下 |
| 原住民 | 都市原住民第二代，部落和城市都像外地 |

**心境主題**：被承諾的未來沒有兌現；晚婚、不婚、不生的猶豫

---

## 4｜00 後（2000–2009）

**關鍵事件**：智慧手機、108 課綱、疫情遠距、AI 衝擊工作、兩岸情勢

| 身分 | 處境 |
|---|---|
| 雙北家庭 | 獨生子女，父母全部的期待壓在身上 |
| 新住民之子 | 媽媽的語言、學校的眼光、兩邊的認同 |
| 鄉鎮青年 | 學校併校、同學外流，家鄉越來越空 |

**心境主題**：社群比較的焦慮、買不起房的放棄感、對未來不確定
